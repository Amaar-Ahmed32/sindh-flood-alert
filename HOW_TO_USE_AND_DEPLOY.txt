🌊 SINDH STREAM 2026-27: FLOOD & HEATWAVE EARLY WARNING SYSTEM
HOW TO RUN LOCALLY, DEMONSTRATE TO JUDGES, AND DEPLOY LIVE ON THE WEB
================================================================================

PROJECT OVERVIEW:
This platform is a production-grade MERN application designed for disaster risk
reduction across all 30 districts of Sindh, Pakistan. It monitors real-time
floods and heatwaves using Open-Meteo Weather and GloFAS Hydrology models,
evaluates risk via scientific thresholds, and delivers multilingual advisories
in English, Urdu (اردو), and Sindhi (سنڌي) with dynamic RTL support.

--------------------------------------------------------------------------------
PART 1: RUNNING LOCALLY ON YOUR COMPUTER (STUDENT LAPTOP)
--------------------------------------------------------------------------------

PREREQUISITES:
- Node.js (v18 or higher) installed on your machine.
- Optional: MongoDB (if not running, the built-in in-memory fallback engages
  automatically so the app NEVER crashes!).

STEP 1: OPEN TERMINAL / POWERSHELL
  cd "sindh-stream-warning"

STEP 2: RUN THE VERIFICATION TEST SUITE
  npm run test
  (This validates the risk scoring thresholds for Jacobabad heat & Sukkur flood)

STEP 3: START BOTH BACKEND & FRONTEND WITH ONE COMMAND
  npm run dev

  What happens:
  - Backend starts on: http://localhost:5050
  - Frontend starts on: http://localhost:5173 (or 5174)
  - Live data automatically synchronizes from Open-Meteo for all 30 Sindh districts.

STEP 4: OPEN IN YOUR BROWSER
  Open http://localhost:5173 to view the dashboard!

  - Click on any district card (e.g., Dadu or Jacobabad) to open the Dossier.
  - Click "🔊 Listen / ٻڌو / سنیں" -> The browser speaks the advisory aloud

    1. Physical Bounds Clamping (5°C to 55°C, no negative rain).

    3. High-Availability Fallback (Live API -> MongoDB Cache -> Baselines).
    4. Real-time Data Confidence Score (98% Live verified).
    5. Local Barrage Gauge Ground-Truth Overrides.

PART 3: HOW TO TAKE THE PROJECT LIVE ON THE INTERNET (FREE HOSTING)
--------------------------------------------------------------------------------

You can deploy the complete project to the web for 100% FREE in about 10 minutes
using MongoDB Atlas (Database), Render/Railway (Backend), and Vercel (Frontend).

--------------------------------------------------------------------------------
STEP A: FREE MONGODB ATLAS DATABASE (2 Minutes)
--------------------------------------------------------------------------------
1. Go to https://www.mongodb.com/cloud/atlas and create a free account.
2. Click "Create a Deployment" -> Choose "M0 Free Shared Cluster".
3. Under "Security Quickstart", create a database username and password.
4. Under "Network Access", add IP address: 0.0.0.0/0 (allow from anywhere).
5. Click "Connect" -> "Drivers" -> Copy your Connection String, e.g.:
   mongodb+srv://student:<password>@cluster0.xyz.mongodb.net/sindh_stream_warning?retryWrites=true&w=majority

--------------------------------------------------------------------------------
STEP B: FREE BACKEND HOSTING ON RENDER (3 Minutes)
--------------------------------------------------------------------------------
1. Push your code to a GitHub repository:
   git init
   git add .
   git commit -m "Sindh STREAM 2026-27 Initial Release"
   git branch -M main
   git remote add origin https://github.com/<your-username>/sindh-stream-warning.git
   git push -u origin main

2. Go to https://render.com and sign in with GitHub.
3. Click "New +" -> "Web Service".
4. Select your GitHub repository.
5. Configure the service:
   - Name: sindh-stream-server
   - Root Directory: server
   - Environment: Node
   - Build Command: npm install
   - Start Command: node server.js
   - Plan: Free
6. Add Environment Variables (under Advanced / Environment):
   - PORT = 5050
   - MONGODB_URI = <paste your MongoDB Atlas connection string from Step A>
   - SYNC_CRON_SCHEDULE = */30 * * * *
   - CLIENT_URL = *
7. Click "Deploy Web Service".
8. Once deployed, Render will give you a public URL, for example:
   https://sindh-stream-server.onrender.com

--------------------------------------------------------------------------------
STEP C: FREE FRONTEND HOSTING ON VERCEL (3 Minutes)
--------------------------------------------------------------------------------
1. Go to https://vercel.com and sign in with GitHub.
2. Click "Add New..." -> "Project".
3. Select your GitHub repository.
4. In Project Settings:
   - Root Directory: click Edit and select "client"
   - Framework Preset: Vite
   - Build Command: npm run build
   - Output Directory: dist
5. Under Environment Variables, add:
   - VITE_API_URL = https://sindh-stream-server.onrender.com
6. Click "Deploy".
7. Vercel will build and give you your live public website URL, for example:
   https://sindh-stream-warning.vercel.app

--------------------------------------------------------------------------------
STEP D: VERIFY YOUR LIVE PRODUCTION DEPLOYMENT
--------------------------------------------------------------------------------
- Visit your Vercel URL on your phone or laptop.
- Open the district map, test language switching, test WhatsApp sharing, and
  test the Scenario Simulator.
- Your project is now globally accessible to judges, mentors, and the public!
